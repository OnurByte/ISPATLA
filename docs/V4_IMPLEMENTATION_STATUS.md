# V4 implementation status

The complete scope and acceptance criteria live in [ISPATLA_MASTER_PLAN_V4.md](ISPATLA_MASTER_PLAN_V4.md). This branch is a local, uncommitted V4 increment based on merged V3 `origin/main`. x-use remains removed: no binary, MCP process, credential bridge, or publishing path was restored, and the pre-existing untracked `x-use/` directory was left untouched.
