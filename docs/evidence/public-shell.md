# Public shell local evidence

The disposable demo Next dev process served `/`, `/docs`, `/security`,
`/privacy`, and `/terms` with HTTP 200. All four information pages expose a
single page heading and public navigation. The product-tour illustration is
explicitly an example. The creator card contains the identity from the master
plan, repository/X links, and the local license; it invents no biography,
profile image, reach or adoption figures.

The in-app browser rendered the landing and documentation/security/privacy/
usage pages. Narrow landing measurements were 360/345 and 333/319 pixels
(viewport/document scroll width); documentation was 360/345 and privacy
333/319. Desktop security measured 1440/1440, and usage measured 962/962.
No horizontal overflow was observed in those measurements. Keyboard Tab
from the creator's GitHub link focused its X link with a visible solid outline;
the narrow card screenshot showed readable content and links.

The browser reported `prefers-reduced-motion: false`. The stylesheet disables
tilt, depth and transition under reduced motion, coarse pointer or no hover,
but those media conditions were not emulated in this run. Pointer-following
motion, a full contrast audit, every breakpoint and authenticated journeys
remain unverified. Scoped ESLint passed. The temporary browser tab, process
and demo database were removed; no external provider write occurred.

The design register describes the intended tokens and motion rules. These
observations establish a local public shell, not a hosted legal policy,
production deployment, live email delivery or live X acceptance.
