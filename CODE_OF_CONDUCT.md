# Contributor Covenant Code of Conduct

## Our pledge

We want participation in İSPATLA to be welcoming and harassment-free for
everyone, regardless of age, disability, ethnicity, gender identity or
expression, level of experience, nationality, personal appearance, race,
religion, or sexual orientation. Be considerate, respectful, and constructive.

## Our standards

Examples of welcome behavior include listening to different experiences,
giving and accepting constructive feedback, and taking responsibility for
mistakes. Unacceptable behavior includes harassment, threats, discriminatory or
sexualized language, personal attacks, and sharing someone's private
information without permission.

## Scope and enforcement

This code applies in repository discussions, issues, pull requests, and other
community spaces, as well as when someone represents the project publicly.
Project maintainers are responsible for clarifying and enforcing these
standards. They may edit or remove contributions and may restrict or end a
person's participation, with a response proportionate to the behavior.

Ask the repository maintainer for a private channel to report a conduct
concern, without posting personal or sensitive details publicly. Reports
will be handled discreetly and reviewed fairly. Use the separate SECURITY.md
process for software vulnerabilities.

This code is adapted from the [Contributor Covenant, version 2.1][covenant].
